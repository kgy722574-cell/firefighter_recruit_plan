# 소방공무원 채용·소방본부 조직업무 조회 앱

## 기능
1. 지역·연도별 소방공무원 채용계획 조회
2. 선택 지역의 2024~2026년 채용 추이 그래프
3. 선택 연도의 지역별 채용규모 비교
4. 평균적인 시·도 소방본부의 표준화된 부서별 업무 조회
5. 업무 키워드로 예상 담당부서 역검색
6. 원자료 CSV 조회 및 다운로드

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 데이터
- `data/소방공무원_3개년_채용계획.csv`: 사용자가 제공한 2024·2025·2026년 채용계획 통합 데이터
- `data/소방본부_표준업무.csv`: 시·도 소방본부에서 일반적으로 나타나는 공통 기능을 조회 편의를 위해 표준화한 참고용 업무 DB

## 주의
`소방본부_표준업무.csv`는 특정 시·도의 공식 직제표가 아닙니다. 실제 부서명·담당업무는 시·도별 조례·규칙과 각 소방본부 최신 조직도에 따라 다를 수 있습니다.

참고로 실제 조직 및 담당업무를 공개하는 소방본부의 예로 경기도소방재난본부의 본부조직도/직원검색 페이지가 있습니다:
